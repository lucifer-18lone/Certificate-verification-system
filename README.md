# Certificate Verification System

A full-stack MERN application for educational organizations and companies to issue, verify, and managed internship certificates.

## 🚀 Features
- **Public Verification**: Instantly check certificate validity using a unique ID.
- **PDF Generation**: Automatically generates professional landing-orientation certificates for download.
- **Admin Dashboard**: Secure access to upload and manage certificate records.
- **Bulk Import**: Process hundreds of certificates at once via Excel upload.
- **Responsive Design**: Fast and clean UI built with Tailwind CSS.

## 🛠️ Prerequisites
- Node.js (v16+)
- MongoDB (Local or Atlas)
- NPM or Yarn
